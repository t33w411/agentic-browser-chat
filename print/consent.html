Print PDFs with Chrome?

ABChat can make PDFs with Chrome's own print engine. They get proper fonts for any language, cleaner page layout, and clickable links and bookmarks.

The assistant also uses it to check how its Word files, decks, and web pages look. A web page runs there as it would on your computer, with no access to ABChat or your other tabs.

While a PDF prints or a file is checked, a tab opens and closes in the background and Chrome shows a banner saying ABChat "started debugging this browser". It lasts a few seconds. ABChat only uses it on that tab, never on your pages.

Fonts are downloaded from jsDelivr, a public font server. The built-in writer needs neither, but it only has standard fonts and Western European characters. You can change this any time in Settings.
